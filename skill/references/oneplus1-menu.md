# 麦当劳「1+1=12元」随心配 · 常见组合参考

> ⚠️ 本表为**参考示例**，帮助电脑小白快速想起自己常吃什么。
> 真实可售商品、分组与价格**一律以 `query-meals`（mcd-mcp）实时返回为准**，skill 运行时会自动核对。

## 玩法一句话说明
从「主餐区」选 1 件 + 从「小食 / 饮品区」选 1 件，两件合计 12 元。
固定口味的人，把这个组合记一次，以后一句话就能复购。

## 主餐区（常见，任选 1）
- 吉士蛋麦满分
- 猪柳蛋麦满分
- 火腿扒麦满分
- 双层吉士堡
- 麦香鸡
- 麦香鱼
- 板烧鸡腿堡
- 照烧鸡腿堡
- 麦辣鸡腿堡
- 那么大鸡排

## 小食 / 饮品区（常见，任选 1）
- 薯条（小）
- 麦辣鸡翅（2 块）
- 鸡块（3 块）
- 玉米杯
- 苹果片
- 吉士蛋堡（部分期次归入此区）
- 可口可乐（小）
- 雪碧（小）
- 美汁源果粒橙（小）
- 冰美式 / 拿铁（小）
- 红茶 / 乌龙茶（小）
- 鲜煮咖啡（小）

## 经典搭配举例（仅供参考）
1. 吉士蛋麦满分 + 薯条（小） —— 早餐快手党
2. 麦香鱼 + 可口可乐（小） —— 午间清爽党
3. 板烧鸡腿堡 + 玉米杯 —— 少油轻负担党
4. 麦辣鸡腿堡 + 鸡块（3 块） —— 管饱党
5. 那么大鸡排 + 冰美式 —— 下午加餐党

> 实际分组与单品以门店当日 `query-meals` 返回标签（通常含「随心配」「1+1」标识）为准。
