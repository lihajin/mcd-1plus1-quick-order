# 麦麦 1+1 一键下单（mcd-1plus1-quick-order）

麦当劳程序员创意开发大赛参赛作品。基于麦当劳 MCP（`mcd-mcp`）能力，把"打开 App → 找 1+1 随心配 → 选两件 → 结算 → 付款"压缩成"说一句话"。

**一句话能力**：首次用大白话告诉它你常吃什么（如"吉士蛋麦满分加小薯条"），它自动查菜单、认商品码、记门店；之后对它发随便一句话（如"来"）就自动调用麦当劳 MCP 重建订单并返回支付链接，直达付款页完成下单。

> 专为**电脑小白**设计：人只说人话，查菜单、认码、选店这些麻烦事全交给 AI 和麦当劳 MCP。

## 它能解决什么
- **决策省心**：1+1 随心配每回都要在几十个单品里挑两件，固定口味的人反复选很烦。
- **操作省时**：从 5 步压成 1 步，一句话触发，直接到支付页。
- **不容易点错**：组合与门店一次锁定，后续零输入。

## 安装与使用（越简单越好）

### 第 1 步：拿麦当劳点餐"钥匙"（MCP Token）—— 一次性
1. 打开 https://open.mcd.cn/mcp ，点右上角【登录】，用手机验证码登录。
2. 点右上角【控制台】→【激活】，同意协议，复制那一串令牌。

### 第 2 步：把"钥匙"装进 WorkBuddy
1. WorkBuddy 左侧【专家·技能·连接器】→【连接器】→ 右上【自定义连接器】→【配置 MCP】。
2. 把下面这段粘进去，把 `YOUR_MCP_TOKEN` 换成你刚复制的令牌，保存并启用 `mcd-mcp`：
```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": { "Authorization": "Bearer YOUR_MCP_TOKEN" }
    }
  }
}
```

### 第 3 步：用起来
打开"麦麦 1+1 一键下单" skill，照提示用大白话说一句你常吃的（如"吉士蛋麦满分加小薯条，到店"），确认一下就完成设置。以后发"来"就直接下单。

> 嫌自己弄麻烦？把麦当劳令牌和 GitHub 令牌发给我（本机本地配置，不会外泄、不会进仓库），我帮你把安装、配置、报名一次性跑通。

## 使用示例
**首次（大白话即可）：**
> 你：帮我设下我常吃的 1+1，吉士蛋麦满分加小薯条，到店
> skill：我帮你认定成 主餐【吉士蛋麦满分】+ 小食【薯条(小)】，合 12 元；到店门店帮你匹配到「XX 麦当劳」。对吗？
